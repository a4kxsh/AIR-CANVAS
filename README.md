# 🎨 AIR CANVAS

A real-time gesture-controlled virtual drawing application built using Python, OpenCV, and MediaPipe.

---

# Features

- Hand gesture drawing
- Shape rendering
- Eraser mode
- Undo / Redo
- Screenshot saving
- Real-time webcam interaction

---

# Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

---

# Installation

```bash
pip install -r requirements.txt
```

---

# Run Project

```bash
python AIR_CANVAS.py
```
